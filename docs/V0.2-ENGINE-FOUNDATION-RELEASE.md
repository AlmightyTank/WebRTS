# WebRTS v0.2 — Engine Foundation Release

## Implemented slices B–H

- **B – Modularization:** minimal Vite entry, Phaser Battlefield scene, terrain renderer, camera/input helpers, separate event-driven input adapter, sidebar/HUD geometry, headless simulation and content registries.
- **C – Versioned schemas:** a v1 command envelope/event contract, shape validation at simulation boundaries, entity validation and matching tests. Existing command builders remain backwards compatible.
- **D – Determinism:** deterministic seed stream (xorshift32), stable game-state hash, preserved entity IDs and tick-indexed accepted-command journal. Replay consistency tests compare independent runs and restored matches. Full rewind/observer replays remain planned for multiplayer.
- **E – Skirmish save/load:** versioned, validated, JSON-serializable match saves preserving projectiles, resources, buildings, units, AI timing, future command queue, event history, RNG state, tick counters and entity IDs. Local autosave every 60 simulated seconds; desktop Shift+S save/Shift+O open (F6/F7 optional), touch Pause → Save / Load. Saves are local to the current browser/device, not cloud synced.
- **F – Data-driven content:** single registry for units, buildings, maps, factions, equipment, weapons, armor and ability descriptors, with cross-reference validation. Damage/combat is not changed by the new metadata.
- **G – Diagnostics:** rolling FPS/slow-frame monitor, frame time and counts, optional F3 overlay with deterministic state hash, and F4 debug-only test unit scenario.
- **H – Validation:** unit and contract tests, deterministic save/load round trips, camera/HUD geometry tests, desktop Chromium gameplay acceptance, mobile portrait/landscape/tablet browser tests with pause/save/load, screenshot artifacts and production build.

## Player controls

Desktop: Esc pause/resume, Shift+S quick save, Shift+O quick load (F6/F7 optional), H diagnostics overlay (F3 is optional where the browser allows it).
Development/e2e only: J spawn stress scenario (F4 optional; not available in production).
Phone/tablet: top-bar **PAUSE** → **SAVE** / **LOAD**. Standard building controls remain unchanged.

## Match serialization and migration

Save storage keys: `webrts.skirmish.v1` (manual), `webrts.autosave.v1` (automatic).
A wrapper includes camera zoom/scroll and a v1 simulation save. Invalid or unknown version saves are rejected without replacing the current match. Legacy internal v0 state has a one-way migration to v1.
Save files are not interoperable with future incompatible content versions without a deliberate migration.

## Limits and follow-up

This is engine groundwork, not full Red Alert-style game completion. No networked multiplayer server or cross-device cloud saves yet. Browser tests use Chromium emulation, not a physical Android/iOS device. Multiplayer replay playback and UI authoring tools are later milestones.
